# 17 — i18n: xabarlarni tarjima qilish

Ikki xil tarjima bor:
1. **Validation xabarlari** — `validator` + `universal-translator` ([08-dto-mapping-validation.md](08-dto-mapping-validation.md)).
2. **Umumiy API xabarlari** ("product not found", email matnlari) — `go-i18n`.

Til `Accept-Language` header'dan olinadi: `Accept-Language: uz` / `ru` / `en-US,en;q=0.9`.

```bash
go get github.com/nicksnyder/go-i18n/v2
go get golang.org/x/text
```

## `pkg/i18n/i18n.go`

```go
package i18n

import (
    "embed"
    "encoding/json"

    goi18n "github.com/nicksnyder/go-i18n/v2/i18n"
    "golang.org/x/text/language"
)

//go:embed locales/*.json
var localeFS embed.FS

type Translator struct {
    bundle *goi18n.Bundle
}

func New() (*Translator, error) {
    b := goi18n.NewBundle(language.English) // fallback
    b.RegisterUnmarshalFunc("json", json.Unmarshal)
    for _, f := range []string{"locales/en.json", "locales/uz.json", "locales/ru.json"} {
        if _, err := b.LoadMessageFileFS(localeFS, f); err != nil {
            return nil, err
        }
    }
    return &Translator{bundle: b}, nil
}

// T — messageID'ni lang bo'yicha tarjima qiladi. Topilmasa messageID qaytadi.
func (t *Translator) T(lang, messageID string, data map[string]any) string {
    loc := goi18n.NewLocalizer(t.bundle, lang) // "uz", "ru", "en-US,en;q=0.9" — hammasini tushunadi
    msg, err := loc.Localize(&goi18n.LocalizeConfig{MessageID: messageID, TemplateData: data})
    if err != nil {
        return messageID
    }
    return msg
}
```

Placeholder: `"Welcome": "Salom, {{.Name}}!"` → `T("uz", "Welcome", map[string]any{"Name": "Ali"})`.

## Middleware — tilni context'ga

```go
package middleware

type langKey struct{}

func Language(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        lang := r.Header.Get("Accept-Language")
        if lang == "" {
            lang = "en"
        }
        next.ServeHTTP(w, r.WithContext(context.WithValue(r.Context(), langKey{}, lang)))
    })
}

func LangFromContext(ctx context.Context) string {
    if l, ok := ctx.Value(langKey{}).(string); ok {
        return l
    }
    return "en"
}
```

## Response'da ishlatish

`response/errors.go`dagi `errMap`ga `messageID` qo'shing:

```go
var errMap = map[error]mapping{
    domain.ErrProductNotFound: {http.StatusNotFound, "PRODUCT_NOT_FOUND", "ProductNotFound"},
    domain.ErrEmailTaken:      {http.StatusConflict, "EMAIL_TAKEN", "EmailTaken"},
    ...
}

// FromError endi translator'ga ega bo'lishi kerak → response paketini struct qiling:
type Responder struct{ tr *i18n.Translator }

func (rs *Responder) FromError(w http.ResponseWriter, r *http.Request, err error) {
    lang := middleware.LangFromContext(r.Context())
    for target, m := range errMap {
        if errors.Is(err, target) {
            JSON(w, m.status, ErrorResponse{Error: ErrorBody{
                Code: m.code, Message: rs.tr.T(lang, m.messageID, nil),
            }})
            return
        }
    }
    ...
}
```

Handler'lar `*response.Responder` oladi (wire orqali). `code` o'zgarmaydi (frontend logika uchun), `message` tarjima qilinadi.

## Validation xabarlarini tilga bog'lash

`pkg/validator`da `Validate(s any, lang string)` — [08](08-dto-mapping-validation.md)dagi ko'p tilli bo'lim. Handler: `h.validator.Validate(req, middleware.LangFromContext(r.Context()))`.

`uz` uchun `universal-translator`da tayyor locale yo'q. Variantlar:
- Har custom+built-in teg uchun `registerTranslation(v, transUZ, "required", "{0} to'ldirilishi shart")` ... (10–15 ta eng ko'p ishlatiladigan teg yetadi).
- Yoki validator xatosini `fe.Tag()` + `fe.Field()` bo'yicha go-i18n orqali tarjima qiling: messageID = `"validation.required"`.

## Qoidalar

1. `code` — hech qachon tarjima qilinmaydi. `message` — tarjima qilinadi.
2. Tarjima fayllari `embed` bilan binary ichida — deploy'da yo'qolmaydi.
3. Fallback har doim `en`. Kalit topilmasa messageID qaytsin, panic emas.
4. Log xabarlari tarjima qilinmaydi — faqat ingliz.
